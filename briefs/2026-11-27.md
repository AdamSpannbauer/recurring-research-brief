## Section 1: Top 5 Papers

1. **From Prediction to Decision: Decision-Focused Fine-Tuning of Autoregressive Tabular Transformers for Cost-Sensitive Financial Events** — Ashkan Golgoon, Giacomo Domeniconi, Samuel Atkins, Sergio Servantez, Zain Khandwala. **arXiv**, submitted **2026-11-25**. Link: ([arxiv.org](https://arxiv.org/abs/2611.34858))  
   Autoregressive tabular transformers are usually trained to predict event labels, then converted into decisions through post-hoc thresholding. This paper instead fine-tunes directly against expected business utility for cost-sensitive financial events, using an amount-scaled action/outcome cost matrix and a closed-form objective over restricted label-token probabilities. The idea is clean: when the downstream action space is already represented as tokens, the model can be optimized for institutional utility without RL sampling, critics, or advantage estimation. KL anchoring and auxiliary language-modeling preserve calibration and event-model quality.  
   **Why you should care:** This is a concrete move from “tabular prediction” to decision-native tabular foundation-model adaptation.

2. **Transferring Architecture as an Optimization Prior** — Vighnesh Subramaniam, Boris Katz, Brian Cheung. **NeurIPS 2026 / arXiv**, submitted **2026-11-25**. Link: ([arxiv.org](https://arxiv.org/abs/2611.34816))  
   The paper treats a randomly initialized architecture’s representational geometry as an optimization prior. Before downstream training, a target network is aligned to the geometry of a different randomly initialized guide architecture, with no labels, gradients from the guide, or learned features transferred. The striking claim is that architectural “fate” can be decoupled from physical structure: shallow networks can inherit some optimization benefits of deeper networks, and coarse representations can be shaped by fine-resolution guides. This is interesting theory-adjacent representation engineering, not another initialization-scale tweak.  
   **Why you should care:** It suggests architecture can be transferred as geometry, not just implemented as layers.

3. **Hierarchical Graph Metanetworks** — Ioannis Kalogeropoulos, Giorgos Bouritsas, Yannis Panagakis. **arXiv**, submitted **2026-11-25**. Link: ([arxiv.org](https://arxiv.org/abs/2611.34726))  
   Weight-space learning has been bottlenecked by graph metanetworks that process every neuron and weight at the finest granularity. This paper introduces hierarchical graph metanetworks that respect neural-network modular hierarchy—neurons, layers, blocks, modules—using permutation-symmetry-preserving pooling and unpooling. The evaluation extends beyond toy MLP/CNN zoos to ResNet-18, ViT, and varying ViT model zoos up to 86M parameters, covering generalization/robustness prediction, Lipschitz-proxy evaluation, backdoor detection, and pruning. The key systems-method insight is that metamodel cost need not scale naively with parameter count.  
   **Why you should care:** It pushes weight-space learning toward realistic model-analysis and model-editing workloads.

4. **Reading Fine-Tuning Diffs Through Lenses: Model Diffing for Backdoor Detection** — Maximilian Petrowitsch, Ben Connors, Chris Kapulkin. **arXiv**, submitted **2026-11-25**. Link: ([arxiv.org](https://arxiv.org/abs/2611.34758))  
   This paper builds a common token-readout scoring system for comparing weight-, activation-, and output-based model-diffing methods for detecting fine-tuning backdoors. The authors introduce lens-based refinements, especially a J++-lens, and report that decoding weight differences through the base model’s J++ lens ranks the backdoor token in the top ten in 11 of 12 settings. The negative result is equally important: output/activation methods and weight-based methods fail under different adversarial transformations, so no single diffing method is robust.  
   **Why you should care:** It sharpens model-diffing from a qualitative interpretability trick into a comparative audit protocol.

5. **Routeability Before Routing: Routeability Audit Protocol (RAP) and RouteabilityBench for Audited LLM Model Selection** — Yihang Lu, Denica Kjorvezir, Ana Gjorgjevikj, Carola Doerr, Tome Eftimov. **NeurIPS 2026 / arXiv**, submitted **2026-11-25**. Link: ([arxiv.org](https://arxiv.org/abs/2611.34825))  
   Router papers often assume there is meaningful per-input variation to exploit. RAP asks first whether a benchmark/model portfolio is “routeable” at all. Across four benchmarks and 66 LLMs, the authors find that common routing enhancements—larger embeddings, dimensionality reduction, abstention, clustering, stronger regressors—do not consistently beat the single best model; gains are concentrated in portfolio-dependent Omni-MATH settings. The paper recommends tied-best analysis, portfolio construction reporting, and family-corrected tests before interpreting router improvements.  
   **Why you should care:** This is the right statistical hygiene for model routing, cascades, and cost-aware agent deployment.

## Section 3: Emerging Trends

- **Decision-native structured modeling is accelerating.** The tabular-transformer financial-event paper optimizes expected utility directly, while recent Text-to-SQL and semantic-query work is doing the same for execution rewards, precision guarantees, or workflow costs.

- **“Benchmark first, router second” is becoming a norm.** RouteabilityBench, DecisionReplay, and recent routing/cascade datasets all emphasize that model-selection claims need portfolio-level diagnosability before algorithmic router comparisons are meaningful.

- **Weight-space and update-space analysis is maturing.** Hierarchical graph metanetworks, model-diff lenses, LoRA singular geometry, and Fisher/update-leverage papers point toward a new layer of tooling that treats checkpoints and diffs as structured data.

- **Causal robustness is moving from point assumptions to ambiguity sets.** Robust recourse under graph ambiguity, causal latent adjustment for world models, and false-positive-controlled causal discovery all frame causal ML as inference under uncertainty over structures, not just mechanisms.

- **Semantic query processing is converging on auditability.** Recent work on semantic views, SemReuse, SignalCount, SQL equivalence proofs, Lean SQL checking, and semantic cache/reuse systems is turning LLM-in-the-database ideas into statistically or formally constrained query operators.

- **Robust Recourse under Causal Graph Ambiguity** — a practical causal recourse framework that searches for actions robust across plausible causal graphs or across a specified graph-weight mass, exposing the coverage–validity tradeoff. ([arxiv.org](https://arxiv.org/abs/2611.34723))

- **Spec2Weights: Certifying Networks that a Language Model Writes from a Specification** — a surprising certification workflow for LLM-written small neural networks, using exhaustive float32 reasoning, SMT, dynamic programming, and recurrence induction. ([arxiv.org](https://arxiv.org/abs/2611.34711))

- **When the Proxy Is Wrong: Mismatch-Corrected Bandits for Adaptive Data Sampling** — formalizes proxy/target mismatch in data selection as a multi-fidelity bandit with paired audits; relevant to data-mixture and active-data-selection pipelines. ([arxiv.org](https://arxiv.org/abs/2611.34707))

- **From NP-Hardness to Exact Tractability Through Sample Abundance** — theory-heavy but provocative: additional observations can make exact optimization tractable for a noisy parity-fitting problem without changing the objective or feasible set. ([arxiv.org](https://arxiv.org/abs/2611.34734))

- **Cache Replacement in Direct-Access Cloud OLAP / LARA** — useful for data-systems people tracking object-store-native analytical engines; the Unified Hit Ratio framing may travel beyond cloud OLAP. ([borowiecki.dev](https://borowiecki.dev/list/cs.DB/new))
