## Section 1: Top 5 Papers

1. **From Interface to Inference: Eliciting Any-Order Inference from Any-Order Models** — Seunggeun Kim, Jaeyeon Kim, Taekyun Lee, Yuyuan Chen, Yilun Du, Sham Kakade, Sitan Chen. **arXiv**, submitted **2026-07-29**. **Link:** ([arxiv.org](https://arxiv.org/abs/2607.26504))  
   This is the most conceptually interesting paper in today’s batch. It argues that masked diffusion models have an “any-order” prediction interface, but not automatically an “any-order” inference procedure: fixed-position token canvases know *what* semantic object belongs but not *where* to put it. The paper proposes insertion-based masked diffusion and latent-space masked diffusion to close that interface–inference gap, with a 7B FlexMDM for Python and a 125M LatentMDM for GSM8K. The important move is treating generation order as a search/inference object, not just a training artifact.  
   **Why you should care:** Any-order inference is a plausible alternative foundation-model primitive for code, tables, edits, and structured reasoning workflows.

2. **Post-Training at the Edge of Detectability: A Game-Theoretic Approach to Fine-Tuning** — Keegan Harris, Brian W. Lee, Ian Waudby-Smith, Philip Amortila, Nika Haghtalab, Michael I. Jordan. **arXiv**, submitted **2026-07-29**. **Link:** ([arxiv.org](https://arxiv.org/abs/2607.26358))  
   This paper gives KL-regularized RL fine-tuning a statistical decision interpretation: the agent optimizes reward while a monitor sequentially tests whether outputs have drifted from a reference policy. The equilibrium objective becomes KL-regularized RL with a coefficient chosen to maximize reward per unit of statistical distinguishability, learned through a fractional-programming reduction. Experiments on Qwen3-8B and Llama-3.2-1B study continual-learning reward–retention trade-offs and suggest an auditing use case for API providers serving open-source models.  
   **Why you should care:** It reframes post-training as constrained statistical detectability, a cleaner lens than heuristic KL-coefficient tuning.

3. **BayesAME: Bayesian Active Model Evaluation** — Paula Cordero Encinar, Taylan Cemgil, Arnaud Doucet, Virginia Aglietti, Silvia Chiappa. **arXiv**, submitted **2026-07-29**. **Link:** ([arxiv.org](https://arxiv.org/abs/2607.27023))  
   BayesAME tackles the increasingly expensive problem of evaluating large generative models on full benchmarks. Rather than requiring a fixed coreset size, it sequentially chooses benchmark items and stops when posterior performance uncertainty and estimate fluctuation fall below user thresholds. The model pools historical model performances through latent item-group abilities and uses information gain for active selection; a multi-target version exploits correlations across target models. The authors explicitly address recent skepticism about non-random coreset selection and find continuous log-likelihood responses more informative than binary scores.  
   **Why you should care:** Evaluation budget is becoming a bottleneck; this is a principled Bayesian design for adaptive benchmark subsampling.

4. **Uncertainty-Guided LLM Semantic Augmentation for Heterogeneous Treatment Effect Estimation** — Jialu Xu, Mengkun Liang, Guannan Liu, Xiaojie Mao, Junjie Wu. **arXiv**, submitted **2026-07-29**. **Link:** ([arxiv.org](https://arxiv.org/abs/2607.26599))  
   CURL is a plug-in representation adapter for CATE estimation that uses estimator uncertainty to decide where frozen-LLM semantic capacity is useful. The key design separates assignment-side and heterogeneity-side channels: role-conditioned prompts produce different semantic representations for nuisance adjustment and treatment-effect heterogeneity, then route them through separated pathways. Across four benchmarks and ten host learners, CURL improves most settings, with ablations and route reassignment analyses supporting the two-channel design. The paper is not merely “LLMs for causal ML”; it uses uncertainty to target semantic augmentation where tabular encodings are locally unstable.  
   **Why you should care:** This is a concrete pattern for combining language priors with causal estimators without pretending LLM embeddings are universally helpful.

5. **High-Order Markov Blanket Discovery via a k-Order Relaxation of the Faithfulness Assumption** — Loong Kuan Lee, Ragavi Krishnamoorthy, Nico Piatkowski. **arXiv / UAI 2026**, submitted **2026-07-29**. **Link:** ([arxiv.org](https://arxiv.org/abs/2607.26357))  
   Most Markov blanket discovery methods rely on faithfulness, which breaks under XOR/parity-type higher-order dependencies and can also fail empirically in finite samples. This UAI 2026 paper relaxes faithfulness to a “k-order” condition that explicitly captures parity-type relationships among k+2 variables, then proposes kOMB as a proof-of-concept Markov blanket discovery algorithm. The contribution is narrow but valuable: it identifies a common structural blind spot in conditional-independence-based discovery and gives an algorithmic route for detecting high-order blankets.  
   **Why you should care:** High-order dependencies are exactly where feature selection, causal discovery, and representation learning can silently fail.

## Section 3: Emerging Trends

- **Inference order is becoming a first-class modeling object.** Any-order masked diffusion, looped/recurrent transformers, sparse memory routing, and retrieval/tool routing all point to the same pressure: autoregressive left-to-right generation is too rigid for structured work.

- **Post-training is being recast statistically.** Recent papers frame fine-tuning through detectability, rank allocation through hypothesis testing, evaluation through Bayesian stopping, and model drift through TV or calibration audits. This is a welcome move from ad hoc knobs to estimable quantities.

- **Tabular foundation model work is entering its “operations manual” phase.** The most useful new TabPFN work is about context sampling, reliability, OOD behavior, privacy, and task transfer, not another headline accuracy claim.

- **LLMs are being used as semantic adapters for structured estimators.** CURL’s uncertainty-guided HTE augmentation, language-model entity matching, and semantic database operators suggest a pattern: frozen LMs provide relational/semantic features, while classical estimators retain the inferential contract.

- **Venue activity around agent data systems is broadening.** cs.DB and workshop streams are converging on agent memory, provenance, structured-data agents, semantic operators, and operational benchmarks.

## Section 4: Worth Watching

- **Understanding Context Sampling in TabPFN on Small Tabular Datasets** — Mohammed Abdullah. Useful practical study of how TabPFN context size and sampling affect stability and accuracy; larger contexts reduce AUC variability, diversity/coverage matter more than mean-matching, and K-means/farthest-point selection can cost much more without accuracy gains. ([arxiv.org](https://arxiv.org/abs/2607.26628))

- **AgentGFM: A Graph Foundation Model with Node-Agent Information-Flow Control** — Jingbo Cui, Jitao Zhao, Di Jin, Dongxiao He. Treats each graph node as an agent that predicts, acts, observes, and corrects its information-flow decisions. Worth watching if graph FMs start influencing relational foundation models. ([arxiv.org](https://arxiv.org/abs/2607.26533))

- **Existence-Field Diffusion Model for Spatial Point Processes with Variable Cardinality** — Xiaoyin Pan, Christian R. Shelton, Rakshith Mahishi, Chengkuan Hong. Introduces continuous “existence variables” so diffusion can model point locations and cardinality jointly without discrete trans-dimensional moves. ([arxiv.org](https://arxiv.org/abs/2607.26428))

- **A Graph-Native Bitemporal Memory Store for Conversational AI Agents** — Alp Niksarli, Gopesh Baheti. Sparse details so far, but the framing is important: agent memory as a bitemporal graph store belongs in data management, not only embedding retrieval. ([arxiv.org](https://arxiv.org/list/cs.DB/recent))
